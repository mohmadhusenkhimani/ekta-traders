# EKTA Traders Website

## Run the website
1. Extract the ZIP file.
2. Open the `EKTA-Traders` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Before publishing
1. Open `js/script.js`.
2. Replace `91XXXXXXXXXX` with the business WhatsApp number (country code + number, digits only).
3. In `index.html`, replace `ADD YOUR BUSINESS NUMBER` and `ADD YOUR BUSINESS ADDRESS`.
4. Update the description, products and images if required.

## Project structure
- `index.html` - website structure and all page sections
- `css/style.css` - layout, colours, responsive design
- `js/script.js` - mobile menu, product filters and WhatsApp enquiry form
- `images/` - the six supplied product images

The website uses HTML, CSS and vanilla JavaScript. Google Fonts are loaded online; a connection is needed for those fonts. The rest of the site runs locally.
